# Documentation

These pages describe the `main` branch, so they can be ahead of the latest release: a feature listed under
`[Unreleased]` in the [changelog](../CHANGELOG.md) is not in the Docker image or the binary yet.

The [documentation site](https://djlechuck.github.io/kinoshelf/) is built when a release is tagged and
describes that release. Start with [Installation](0-installation.md).
